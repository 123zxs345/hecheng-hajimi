# 合成哈基米

浏览器合成小游戏，保留原有猫咪素材、音效、音乐和碰撞手感。手机和电脑打开网页即可玩；微信小游戏源码保留在原项目中。

手机首屏以棋盘为主，去掉重复标题与画布设置区，游戏框和猫图一起等比例放大。改名、音效开关、四首背景音乐选择位于上方；左右拖动瞄准、松手投放，上下滑动浏览页面。游戏结束直接显示“分享获取复活币”和“送作者一包辣条”。

游戏上方的“音乐音量”滑块支持 0% 至 100%，调节立即生效并保存在当前浏览器，切歌和刷新后保留；0% 静音音乐，合成音效使用自己的开关。四首现成录音经两遍响度处理统一到约 -14 LUFS，默认播放音量为 36%，比之前的默认听感稍响。歌曲、人声、旋律和速度保留，处理与最终响度测量记录位于音乐素材 manifest。

统计入口：https://123zxs345.github.io/hecheng-hajimi/stats.html 。展示累计玩家、今日活跃、累计/今日游玩时长，以及最近 30 日日活与时长。新版启用后首次实际投放才计为玩家，按匿名浏览器在北京时间每天去重；只计前台、有焦点、未暂停/未开弹窗的时间，60 秒无操作停止计时。约每 30 秒同步，离线待交记录会补交；换浏览器或清存储计为新匿名玩家。统计页为公开汇总页，不提供私有管理员权限或服务器级防伪。

## 托管结构

- GitHub Pages 发布 `dist/` 的静态网页、封面和图片；游戏计算在玩家浏览器。
- 独立 TinyWebDB 游戏账号保存公开昵称、历史最高分和邀请记录。排行榜从所有有效玩家记录中选最高的 20 名，不是最近 20 次提交。
- 匿名身份、个人最好成绩、复活币账本保存在当前浏览器。刷新保留；换浏览器或清理存储会生成新身份，不提供跨设备账号同步。
- 新玩家有 1 枚初始币；新朋友经邀请链接完成首次合成后，邀请者获得 1 枚，每个北京时间自然日最多 5 枚。打开、复制链接和取消分享均不发币。
- 自愿请作者吃辣条：展示作者提供的真实微信收款码，金额随心；玩家点击“我已支持”当日赠 1 枚，不填写单号，不检测付款。
- 一局最多使用 1 枚币。小游戏为休闲分享用途；纯前端公开榜单不提供比赛级成绩认证。
- 超过 100000 分的本局视为异常，整局不参与排行榜；此前该局已同步的成绩也会撤出，保留之前有效局纪录。正好 100000 分可以上榜，旧数据中的超限成绩同样排除。
- 四首背景音乐可自由切换，选择和音效开关保留在浏览器。两首更新曲目直接使用现成录音：慎啸的[哈基米·Wake](https://www.bilibili.com/video/BV1UkW3zdEMw/)（原曲 Wake，255 秒）和[青米（青鸟）](https://www.bilibili.com/video/BV1iixTzwEYJ/)（原曲 青鸟，98 秒）。保留完整伴奏，只做音量均衡、MP3 压缩与边缘淡入淡出；没有重新作曲或合成人声。来源和文件校验记录见 `public/minigame/assets/music/manifest.json`。

## 发布

1. 将本目录的源码推送到 `123zxs345/hecheng-hajimi` 的 `main`。
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. Settings → Secrets and variables → Actions → **Variables** 中设置 `TINYWEBDB_USER` 和 `TINYWEBDB_KEY`；它们是此游戏专用的公开数据库连接信息，构建后包含在网页中。不要填登录密码，也不要复用含私人数据的数据库账号。
4. Actions → Publish 合成哈基米 → Run workflow。部署成功后，以 Pages 页面返回的实际链接为准。

无需 npm 安装依赖。构建：

```text
node --test tests/*.test.mjs
node scripts/build.mjs
node scripts/preview.mjs
```

本地测试地址是 `http://127.0.0.1:4196/hecheng-hajimi/`，故意保留仓库子路径，检查图片、音频、邀请链接不会跑到域名根目录。

数据库未配置或暂时离线时，游戏、个人成绩、收款码、支持感谢币和已有复活币仍可使用；在线榜单和新邀请奖励需数据库恢复后同步。没有使用参考游戏作者的数据库账号，也不使用共享测试账号。

## 自己的域名

有域名后可以在 Settings → Pages → Custom domain 中配置，再按 GitHub 返回的要求设置 DNS。自动构建会使用 Pages 当前域名生成封面和链接的绝对地址。当前没有购买或绑定域名。

GitHub Pages 与 TinyWebDB 都需要在目标大陆普通网络实测。新托管地址部署成功不等于所有地区均可达。
